# Module 00 Assignments

**A0.1: Comparison table.** From memory, build a VM vs container table with at least 6 rows
(isolation, boot time, size, OS, portability, density). Then check it against the README.

**A0.2: Manager explainer.** Write ≤150 words explaining to a non-technical manager why the company should
use containers. Include at least two of the four benefits and one analogy of your own.

**A0.3: VM or container?** For each, choose and justify in one sentence:
1. Running untrusted code from anonymous users.
2. 40 microservices on one server.
3. A legacy app needing a specific Windows kernel.
4. CI jobs that need a clean environment each run.
5. Running a different OS family than the host.

**A0.4: Draw the flow.** Draw what happens, step by step, when you type `docker run -d nginx` on a host that has never seen nginx.

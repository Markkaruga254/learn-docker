# Roadmap & progress tracker

Copy this file's checkboxes into your own fork and tick as you go.

## Suggested 4-week schedule (about 10 to 12 h/week)
| Week | Modules |
|------|---------|
| 1 | 00 Foundations, 01 Setup, 02 Core CLI |
| 2 | 03 Networking, 04 Storage, 05 Dockerfiles (start) |
| 3 | 05 finish, 06 Compose, 07 Registry, 08 Course project |
| 4 | 09 Production practices, 10 Capstones, Final exam |

## Checklist
- [ ] **00 Foundations**: labs, assignments, quiz (score ≥ 80%)
- [ ] **01 Setup**: Docker running, `hello-world` works, instance stop routine practised
- [ ] **02 Core CLI**: labs, 25-command drill, break-and-fix, quiz
- [ ] **03 Networking**: labs, assignments, quiz
- [ ] **04 Storage**: labs (incl. backup/restore), assignments, quiz
- [ ] **05 Dockerfiles**: labs, size challenge, caching challenge, quiz
- [ ] **06 Compose**: labs, assignments, quiz
- [ ] **07 Registry**: pushed and pulled your own tagged image
- [ ] **08 Course project**: site live from Docker Hub on a clean host
- [ ] **09 Production practices**: labs, scan an image, quiz
- [ ] **Capstone Tier 1** (static site)
- [ ] **Capstone Tier 2** (API + DB + reverse proxy)
- [ ] **Capstone Tier 3** (secured image + CI + deploy)
- [ ] **Final exam** (≥ 80%)
- [ ] **Confidence matrix** completed

Pass rule for a module: you finished every lab without copy-paste, did the assignments without
peeking, and scored ≥ 80% on the quiz. If not, repeat the weak labs.
